# Landing Personal – Benjamin Dalmau

Este repositorio contiene una landing page personal desarrollada con **HTML, CSS y JavaScript**, compuesta por tres secciones principales:

## 📌 Secciones del sitio

### **1. Mis Servicios**

Página donde presento los servicios que ofrezco. Incluye una estructura clara y visual para que los clientes puedan conocer qué hago y cómo puedo ayudarlos.

### **2. Contacto**

Formulario funcional que permite a los usuarios enviarme un mensaje con sus datos.
Incluye validaciones básicas con JavaScript.

### **3. Mi CV**

Versión online de mi currículum, diseñada con HTML y CSS.
Organizada de forma limpia y accesible para visualizar experiencia, educación y habilidades.
